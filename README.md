# pedrovinces.com.br

Página pessoal e profissional do Dr. Pedro Vinces (Medicina Intensiva e Tecnologia em Saúde).

Site estático em um único `index.html` (CSS e JS embutidos), publicado pelo GitHub Pages com domínio próprio (`CNAME`).

## Editar textos

- Português: direto no HTML.
- Inglês: objeto `EN` no script ao final do `index.html` (mesmas chaves dos atributos `data-i18n`).

## Publicação

GitHub Pages servindo a branch `main`, pasta raiz. DNS na Locaweb apontando para o GitHub Pages.
